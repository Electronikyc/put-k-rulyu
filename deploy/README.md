# Отчет по репетиции деплоя проекта «Путь к Рулю»

## Схема архитектуры
Браузер пользователя -> Nginx (порты 80/443, HTTPS) -> Статические файлы (HTML, CSS, JS).

## Таблица сервисов
| Сервис | Технология | Внутренний порт | Продакшен-сервер |
|--------|------------|-----------------|------------------|
| web    | Nginx      | 80, 443         | Nginx            |

## Переменные окружения и секреты
В данном проекте не используются серверные секреты. Ключи Firebase являются публичными.

## Команды для запуска и остановки
- Запуск: `docker compose up --build -d`
- Остановка: `docker compose down`

## Список ошибок и решений
1. *Ошибка TLS handshake timeout при сборке Docker.* Решение: настройка зеркала Docker Hub в настройках Docker Desktop.
2. *Ошибка auth/unauthorized-domain в Firebase.* Решение: добавление домена `put-k-rulyu.localhost` в Authorized domains в консоли Firebase.

## Что нужно изменить для публикации на реальном сервере?
Для публикации проекта в интернете потребуется арендовать сервер (VPS), зарегистрировать реальное доменное имя, получить публичный SSL-сертификат (например, через Let's Encrypt) и настроить CI/CD для автоматической доставки обновлений.
